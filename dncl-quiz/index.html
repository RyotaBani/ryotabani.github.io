プログラムの穴埋め演習

共通テストと同じ書き方のプログラムの空欄に、選択肢をはめて実行します。正しく動くか、その場で確かめられます。

問1

    空欄をタップしてください

    空欄をタップして選び、ここの選択肢をタップすると空欄に入ります。入れ直しもできます。

    表示された内容

    変数と配列 いま変わったものは黄色

    「1行ずつ実行」を押すと、ここに変数の値が出ます。
    ← 前の問題 次の問題 →

    問題ごとにURLが分かれています（例：/dncl-quiz/#q3）。授業で1問だけ配るときは、その問題を開いた状態のURLを共有してください。入力した答えはこの端末の中だけで処理され、どこにも送信されません。

    穴埋め問題は「入れて動かす」と分かる

    共通テスト「情報Ⅰ」のプログラムの問題は、ほとんどが「空欄に入るものを解答群から選ぶ」形です。紙の上で解くときは、頭の中でプログラムを1行ずつ動かし、変数の値を追いかける必要があります。これをトレースといいます。慣れないうちは、どの値がどこで変わったのかを見失いやすく、なんとなく選んでしまいがちです。

    この演習では、空欄に選択肢を入れると、そのプログラムを本当に実行して結果を確かめられます。正しくないものを入れたときに何が表示されるのかも見られるので、「なぜこれではだめなのか」まで理解できます。プログラムの書き方は、大学入試センターが公開している「共通テスト用プログラム表記」に合わせています。

    使い方

    1. 上の一覧から問題を選びます。★の数が多いほど難しい問題です。
    2. プログラムの中の点線の枠（空欄）をタップします。右側に、その空欄に入れられる選択肢が出ます。
    3. 選択肢をタップすると空欄に入ります。空欄が2つある問題は、もう1つの空欄も同じように埋めます。
    4. 「▶ 実行して判定」を押すと、プログラムを実行して、正しく動いたかどうかを表示します。入力を使う問題は、いくつかの値で続けて試します。
    5. 「1行ずつ実行」を押すと、1回押すごとに1行ずつ進みます。黄色の行がこれから実行する行です。右下の表で、変数の値がどう変わるかを確かめましょう。

    まちがえたときは、表に「あなたのプログラムの表示」と「正しい表示」が並びます。どこで食い違ったのかを考えてから、1行ずつ実行して確かめると、理解が深まります。

    穴埋め問題を解くコツ

    1. 変数の役割を先に確かめる

    プログラムを読む前に、それぞれの変数が「何を表しているか」を確かめます。問3の i は「何日目か」を数えるための変数で、dan は「その日に上る段数」を表しています。どちらも数が入りますが、役割はまったくちがいます。「数えるための変数」と「値を表す変数」を区別できると、選択肢をしぼりやすくなります。

    2. 境目の値で試す

    条件分岐の問題では、> と >= のどちらが入るかを問うものがよく出ます。こういうときは「ちょうど境目の値」を入れて考えます。問2なら、14日目と15日目です。14日目が期限内なら、延滞になるのは「14より大きいとき」なので > です。境目の1つだけで判断せず、その前後の値でも確かめるとまちがいが減ります。

    3. 同じ値が出てきたらどうなるかを考える

    問4のように、配列の中に同じ値がくり返し出てくるときは要注意です。最大値を探すとき、> を使うと「それまでより大きいとき」だけ入れかえるので最初に出てきた位置が残り、>= を使うと最後に出てきた位置が残ります。問題文に「先に来た日」「後の日」などの指定がないかを必ず確かめましょう。

    4. 添字が0から始まるか1から始まるか

    共通テスト用プログラム表記では、配列の添字（何番目かを表す数）は、特に説明がなければ0から始まります。Kion[0] が1日目、Kion[1] が2日目です。人に見せるときに「何日目」と表示したいなら、添字に1を足す必要があります。問4の最後の行で hi + 1 としているのはそのためです。

    5. 計算の順番と「÷」に気をつける

    共通テスト用プログラム表記では、/ はふつうの割り算、÷ は商（割り算の答えの整数部分）を求める記号です。% は余りを求めます。問5では、÷ を使うと小数の部分が消えてしまい、正しい平均が出ません。また、四捨五入や切り捨てをしてから掛け算をするのか、掛け算をしてから四捨五入をするのかで、結果が変わります。

    それぞれの問題のねらい

    問題★学ぶこと
    問1 箱の中身を入れ替える★代入すると前の値が消えること。一時的な変数の使い方
    問2 図書室の返却期限★比較の記号（> と >=）と境目の値
    問3 階段トレーニング★★繰り返しで合計を求める。数える変数と値の変数のちがい
    問4 いちばん暑かった日★★★配列から最大値とその位置を探す。同じ値があるときの扱い
    問5 平均点を小数第1位まで★★関数（四捨五入）と、計算の順番。/ と ÷ のちがい
    問6 貸出機の待ち時間★★★シミュレーションをプログラムで書く。時刻を表す変数の更新

    問6は、待ち行列（順番待ちの列）をプログラムでシミュレーションする問題です。「来た時刻」「始める時刻」「空く時刻」の3つを区別することがポイントです。シミュレーションとデータ分析を組み合わせて考える練習は、領域をまたぐ演習にまとめています。

    授業での使い方

    授業の最初の5分で1問だけ解く小テストとして使えます。問題ごとにURLが分かれているので、たとえば https://joholab.net/dncl-quiz/#q2 を配れば、生徒は問2から始められます。登録やログインは要りません。入力した答えはその端末の中だけで処理され、どこにも送られません。

    おすすめの進め方は、まず何も見ずに選択肢を選ばせ、「なぜそれを選んだのか」を一言で書かせてから実行させる方法です。まちがえた生徒には、1行ずつ実行して、自分の予想と変数の値がどこで食い違ったかを探させます。正解した生徒には、わざと別の選択肢を入れて、何が表示されるかを予想させると、理解の確認になります。

    自分でプログラムを書いたり、解答群をまとめて比べたりしたいときは、共通テスト用プログラム表記を動かそうを使ってください。空欄を【ア】のように書いたプログラムを貼り付けると、選択肢を1つずつ入れて結果を一覧で比べられます。
