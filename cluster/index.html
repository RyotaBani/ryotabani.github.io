クラスタリングとは

たくさんのデータがあるとき、似たものどうしをまとめて グループ に分けることをクラスタリングといいます。できたグループをクラスタと呼びます。

特徴は、正解を教えないことです。「これはAグループ」といったラベルは一切与えません。データの位置関係だけを見て、コンピュータが自分でまとまりを見つけます。教師なし学習の代表例です。

そのため、できたグループが何を意味するかは、あらかじめ決まっていません。結果を見て人が「これは若い層だ」「これは購入頻度の高い客だ」と解釈します。

k-means法のしくみ

最もよく使われる手法が k-means法（k平均法）です。手順は驚くほど単純です。

  1. 中心を適当に置く：分けたいグループの数だけ、点を適当な位置に置きます
  2. 振り分ける：各データを、いちばん近い中心のグループに入れます
  3. 中心を動かす：各グループに集まったデータの平均の位置へ、中心を移動します
  4. くり返す：2と3を、中心が動かなくなるまでくり返します

この4つだけです。中心が動かなくなれば完成で、たいてい数回のくり返しで落ち着きます。上のツールで、1歩ずつ進めながら確かめられます。

名前の「means（平均）」は、手順3で平均を使うことに由来します。「k」は分けるグループの数で、人が指定します。

なぜこれでうまくいくのか

この手順は、ある値を小さくするように働いています。各データから、自分が属するグループの中心までの距離。その二乗の合計です。

まとまりの良さ ＝ Σ（各データから、属する中心までの距離）²

手順2では、より近い中心に移すので、この合計が減ります。手順3では、平均の位置が距離の二乗和を最小にするので、やはり減ります。減り続けて、それ以上減らなくなったところで止まる。だから必ず終わります。

グループ数をどう決めるか

k-means法の弱点は、分ける数を人が決めなければならないことです。データを見ただけでは、いくつが適切か分かりません。

判断の目安になるのがエルボー法です。グループ数を1から順に増やしながら、まとまりの良さを計算してグラフにします。

グループ数を増やせば、まとまりは必ず良くなります。極端な話、データの数だけグループを作れば、まとまりは完璧です。しかしそれでは意味がありません。

グラフを見ると、ある数を境に改善の度合いが急に鈍る場所があります。ひじ（elbow）のように折れ曲がるので、エルボー法と呼ばれます。その折れ曲がる点が、適切なグループ数の目安です。

ただし、これは絶対的な答えではありません。目的によって適切な数は変わります。顧客を分けるとき、施策を打てるのが3種類までなら、3つに分けるのが実用的です。

注意すべき点

初期位置で結果が変わる

最初に中心を置く位置によって、たどりつく答えが変わることがあります。偶然、悪い位置から始まると、不自然な分かれ方で止まってしまいます。

対策として、初期位置を変えて何度か実行し、最もまとまりの良い結果を採用する方法がとられます。

丸いかたまりを想定している

k-means法は、距離だけを見てグループを作ります。そのため、丸く集まったデータには強い一方、細長い形やドーナツ状のデータはうまく分けられません。

そうした場合は、密度に注目する手法や、階層的にまとめていく手法など、別の方法が使われます。

かたまりがなくても分けてしまう

データが均一に散らばっていても、k-means法は指示された数のグループに分けます。「分かれていません」とは答えてくれません。

結果が出たからといって、そこに意味のあるまとまりがあるとは限らない。この点は必ず意識しておく必要があります。上のツールの「かたまりなし」で、この様子を確かめられます。

データの単位をそろえる

実際のデータでは、項目ごとに単位や桁が違います。年齢は0〜100、年収は0〜1000万。このまま距離を計算すると、桁の大きい年収だけで結果が決まってしまいます。

そこで、あらかじめ各項目を同じ尺度にそろえます。これを標準化や正規化といいます。前処理を怠ると、意味のない結果が出ます。

ほかのクラスタリング手法

k-means法は最も基本的な方法ですが、ほかにもいくつかの手法があります。

手法特徴
階層的クラスタリング近いものから順にまとめていく。グループ数を先に決めなくてよい
密度による手法点が密集した領域をグループとみなす。細長い形にも対応できる
混合ガウスモデルそれぞれのグループを確率分布として扱う。所属を確率で表せる

階層的クラスタリングでは、まとめていく過程を樹形図（デンドログラム）として描けます。どこで切るかによってグループ数を後から選べるのが利点です。

結果をどう解釈するか

クラスタリングで難しいのは、計算よりもできたグループの意味づけです。コンピュータは「これが1番のグループ」としか教えてくれません。

顧客データを3つに分けたとき、それぞれの平均を見比べます。「このグループは購入頻度が高く、単価は低い」「こちらは年に数回だが高額商品を買う」。こうして特徴を読み取り、名前をつけていきます。

この作業には、データそのものだけでなく、業務や分野についての知識が必要です。分析は計算で終わりではなく、解釈まで含めて初めて役に立ちます。

使い方

  • グループ分けの過程：「1歩すすめる」で、振り分けと中心の移動を交互に確認できます。中心が動かなくなったら完成です。
  • いくつに分けるか：エルボー法のグラフで、適切なグループ数の目安を確かめられます。
  • どこで使われるか：実際の活用例と、教師あり学習との違いを整理しています。
