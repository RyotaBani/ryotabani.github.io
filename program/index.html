共通テスト用プログラム表記を動かそう

共通テスト「情報Ⅰ」と同じ書き方のプログラムを、その場で実行できます。1行ずつ進めて、変数の値の変わり方を確かめましょう。

プログラムは、問題文などからそのまま貼り付けても動きます。行の先頭の (1) や (01) の行番号は読み飛ばします。字下げは「｜」「⎿」でも、空白でもかまいません。

空欄に入れて試す

入れた内容は「▶ 実行」「1行ずつ」に使われます。空欄は【ア】のように、【】の中にカタカナで書きます。

に入れる候補を、1行に1つずつ
「▶ 実行」か「1行ずつ」を押してください。

表示された内容

変数と配列 いま変わったものは黄色

実行すると、ここに変数の値が表示されます。

トレース表

トレース表は、1行実行するごとの変数の値を記録した表です。値が変わったところは黄色になります。

「プログラムを動かす」のプログラムを、フローチャートで表します

ひし形は分岐（条件で道が分かれる）、上下が角を落とした形は繰り返しの始まりと終わり（ループ端）、平行四辺形は入力と表示です。

「プログラムを動かす」のプログラムを、同じ動きのPythonに書きかえて表示します

書き方が違っても、順次・分岐・反復の組み立ては同じです。行どうしを見比べてみましょう。

共通テスト用プログラム表記とは

    
高校の「情報Ⅰ」の授業では、Python、JavaScript、VBA など、学校によってさまざまなプログラミング言語が使われています。そのため大学入学共通テスト「情報Ⅰ」では、特定の言語ではなく、日本語を交えた共通テスト用プログラム表記でプログラムが出題されます。大学入試センターは、試作問題の公表にあわせて、この表記の基本を例示しています。

    
ただし、例示はあくまで基本です。センターも、問題文を簡潔にするなどの理由で、例示と違う形で出題することがあると説明しています。実際の試験では「配列の添字は 1 から始まる」「最大値(x, y) は大きいほうを返す」のように、問題文で決まりが追加されます。このページでは、例示の書き方に加えて、そうした問題文の決まりにも合わせられるようにしています。


    
プログラムの3つの基本構造

    
どんなプログラムも、順次・分岐・反復の3つの組み合わせで書けることが知られています。

    
    
      
  • 順次：上から順に1行ずつ実行する。見本「おつりの計算」
    • 
      
  • 分岐：条件によって実行する部分を選ぶ。「もし … ならば:」「そうでなくもし … ならば:」「そうでなければ:」で書く。見本「点数で評価する」
    • 
      
  • 反復：同じ処理をくり返す。回数が決まっているときは「x を 0 から 9 まで 1 ずつ増やしながら繰り返す:」、条件で決めるときは「n < 10 の間繰り返す:」と書く
    • 
    

    
分岐や反復の中で実行する範囲は、行の先頭の「｜」で表し、範囲の最後の行には「⎿」を付けます。分岐の中に反復があるように入れ子になると、｜ が重なります。最後の行で2つの範囲が同時に終わるときは「⎿ ⎿」のように重ねて書きます。「フローチャート」のタブで、範囲がどこからどこまでかを図で確かめられます。


    
変数と配列

    
変数は、値を入れておく名前つきの箱です。kosu = 3 は「kosu という箱に 3 を入れる」という意味で、数学の等式ではありません。だから n = n + 1 は「n の今の値に 1 を足して、n に入れ直す」ことになります。

    
配列は、同じ種類の値をまとめて並べたものです。名前の先頭を大文字にし、Tokuten[2] のように添字（番号）で1つ1つの値を指します。特に説明がなければ、添字は 0 から始まります。要素が6個の配列なら、添字は 0 から 5 までです。「まちがい探し」の見本では、添字を 1 から数えて範囲の外に出てしまう例を確かめられます。

    
一方、実際の共通テストでは「すべての配列の添字は 1 から始まる」と問題文で決めることもあります。そのときは「配列の添字を 1 から始める」にチェックを入れると、配列の最初の値を添字 1 で読み書きします。


    
演算子

    

      
書き方意味例

      
+ - * /四則演算7 / 2 は 3.5

      
÷整数の割り算の商7 ÷ 2 は 3

      
%整数の割り算の余り7 % 2 は 1

      
**べき乗2 ** 10 は 1024

      
== != > < >= <=比較x != 0

      
and or not論理演算x >= 0 and x < 10

    

    
「÷」と「%」の組み合わせは、2進数への変換や、偶数・奇数の判定、桁の取り出しなどでよく使われます。見本「10進数を2進数に直す」で、余りを1つずつ並べていくようすをトレース表で追ってみましょう。


    
トレース表で動きを追う

    
プログラムの問題では、変数の値が1行ごとにどう変わるかを追えるかどうかが大切です。紙の上で、行番号と変数の値を表に書き出していく方法をトレースといい、その表をトレース表といいます。

    
このページでは、実行すると自動でトレース表を作ります。値が変わったところは黄色になります。まず自分でトレース表を書き、そのあとで実行して答え合わせをすると、どこで考え違いをしたかが分かります。「1行ずつ」のボタンを使えば、次に実行する行を確かめながら1行ずつ進められます。


    
空欄に入れて比べる

    
共通テストのプログラムの問題では、プログラムの一部が空欄になっていて、入る式や文を解答群から選ぶ形がよく出ます。プログラムの中に 【ア】 のように書くと、このページでは空欄として扱います。

    
「解答群で比べる」に候補を1行に1つずつ書き、「それぞれ実行して比べる」を押すと、それぞれを入れて実行した結果が表に並びます。正しい選択肢だけでなく、まちがった選択肢を入れると何が起きるかを確かめると、なぜその式でなければならないのかが分かります。見本「空欄のあるプログラム」で試してみてください。


    
Pythonとのちがい

    
共通テスト用プログラム表記で書いたプログラムは、ほかの言語にほぼそのまま書きかえられます。「Pythonと見比べる」のタブでは、同じ動きをする Python のプログラムを表示します。主なちがいは次のとおりです。

    

      
共通テスト用プログラム表記Python

      
表示する(x, "円")print(x, "円", sep='')

      
要素数(Data)len(Data)

      
a ÷ ba // b

      
i を 0 から 9 まで 1 ずつ増やしながら繰り返す:for i in range(10):

      
x < 10 の間繰り返す:while x < 10:

      
｜ と ⎿ で範囲を表す字下げ（空白）で範囲を表す

    

    
Python の range(10) は 0 から 9 までで、10 を含みません。「9 まで」と「range(10)」のように、終わりの数の書き方が1つずれることに注意しましょう。


    
使い方

    
    
      
  • プログラムを動かす：見本を選ぶか、プログラムを書いたり貼り付けたりして「▶ 実行」を押します。「ゆっくり実行」で、実行中の行を目で追えます。止まらないプログラムは「■ 止める」で止められます。
    • 
      
  • 入力：【整数を入力】 などがあると、実行がそこで止まり、入力欄が出ます。
    • 
      
  • ファイル：「ファイルに保存」でテキストファイルとして保存し、「ファイルを読み込む」で開けます。プログラムがこのページの外に送られることはありません。
    • 
      
  • フローチャート：プログラムの流れを図にします。分岐はひし形、繰り返しはループ端の記号で表します。
    •
