コンピュータは「スイッチの集まり」

コンピュータの中で計算をしているのは、無数の小さなスイッチです。電気が流れているか、いないか。この2つの状態を1と0に対応させ、その組み合わせであらゆる処理を行っています。

このスイッチの働きを整理したものが論理回路です。入力の組み合わせに対して、出力がどうなるかというルールを持っています。

基本の3つ

論理回路の基本は、AND・OR・NOT の3種類です。この3つを組み合わせれば、どんな複雑な処理も作れることが知られています。

AND（論理積）

入力が両方とも1のときだけ、出力が1になります。「AもBも」という条件です。

身近な例では、電子レンジがあります。「スタートボタンが押されている」かつ「扉が閉まっている」の両方が満たされたときだけ動きます。

OR（論理和）

入力のどちらか一方でも1なら、出力が1になります。「AまたはB」という条件です。

非常ベルが分かりやすい例です。1階のボタンか2階のボタンか、どれか1つでも押されれば鳴ります。

NOT（否定）

入力を逆にします。1が入れば0を、0が入れば1を出します。入力は1つだけです。

組み合わせた回路

名前意味出力が1になるとき
NANDANDの否定両方が1のとき以外
NORORの否定両方が0のときだけ
XOR（排他的論理和）どちらか一方だけ2つが異なるとき

XORは「違っていれば1」という回路で、誤り検出や暗号でよく使われます。2つの値が同じかどうかを調べるのに便利だからです。

真理値表

入力のすべての組み合わせに対して、出力がどうなるかを一覧にした表を真理値表といいます。

入力が2つなら、組み合わせは 00・01・10・11 の4通りです。入力が3つなら8通り、n個なら2のn乗通りになります。真理値表を作れば、その回路の動きを完全に説明できます。

入力が n 個 → 組み合わせは 2n 通り

足し算をする回路

論理回路で本当に計算ができるのか。実際に確かめてみましょう。1桁の2進数の足し算を考えます。

計算結果和（S）くり上がり（C）
0 + 0000
0 + 1110
1 + 0110
1 + 11001

ここで、和（S）の列をよく見てください。2つが異なるときだけ1になっています。これはXORとまったく同じです。

次に、くり上がり（C）の列を見ます。両方が1のときだけ1です。これはANDそのものです。

つまり、XORとANDを1つずつ並べるだけで、1桁の足し算ができる回路になります。これを半加算器といいます。上のツールで実際に動かせます。

桁を増やすには

半加算器には弱点があります。下の桁からのくり上がりを受け取れないのです。そこで入力を3つ（A、B、下からのくり上がり）にした全加算器を作り、それを桁数だけ並べます。

8桁の足し算なら全加算器を8個、64桁なら64個。実際のCPUの中では、この構造がびっしりと並んでいます。あらゆる計算の土台が、AND・OR・NOTの組み合わせでできているのです。

電子部品としての論理回路

これらの回路は、トランジスタという小さな部品を組み合わせて作られています。トランジスタは電気の流れを制御するスイッチで、現代のCPUには数百億個が詰め込まれています。

興味深いことに、NANDだけですべての論理回路を作れることが知られています。ANDもORもNOTも、NANDの組み合わせで表現できるのです。この性質を完全性といい、実際の製造でも、同じ部品を並べればよいという利点があります。

プログラムの中の論理

論理回路の考え方は、ハードウェアだけの話ではありません。プログラムの条件分岐でも同じ論理が使われます。

もし（気温が30度以上）かつ（湿度が70%以上）ならば、警報を出す

これはANDです。多くのプログラミング言語では、ANDを「and」や「&&」、ORを「or」や「||」、NOTを「not」や「!」と書きます。表現は違っても、考え方は論理回路と同じです。

ド・モルガンの法則

論理には、便利な変換の決まりがあります。代表的なのがド・モルガンの法則です。

「AかつB」でない　＝　「Aでない」または「Bでない」
「AまたはB」でない　＝　「Aでない」かつ「Bでない」

言葉で確かめてみましょう。「雨でも雪でもない」は「雨でない、かつ、雪でない」と同じです。逆に「雨と雪が両方ではない」は「雨でない、または、雪でない」になります。

この法則は、条件式を書きかえるときに役立ちます。プログラムの条件が複雑になったとき、より読みやすい形に整理できるのです。回路の設計でも、使う部品の種類を減らすために使われます。

記憶する回路

ここまでの回路には、共通する性質があります。入力が決まれば出力が決まり、それ以前の状態は関係ありません。こうした回路を組み合わせ回路といいます。

しかしコンピュータには、値を覚えておく仕組みも必要です。そこで、出力を入力に戻す構造を作ります。すると回路が状態を保持できるようになり、1ビットの記憶装置になります。これをフリップフロップといい、順序回路と呼ばれます。

メモリやレジスタは、この記憶回路を大量に並べたものです。計算する回路と記憶する回路。この2つが揃って、コンピュータが成り立っています。

使い方

  • 基本の回路：回路を選び、スイッチを押すと出力が変わります。真理値表の該当する行が光ります。
  • 足し算する回路：半加算器を動かせます。1+1のときにくり上がりが出る様子を確認してください。
  • 真理値表クイズ：表を見て、どの回路かを当てる練習ができます。
